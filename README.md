# AI Stock Predictor

AI-powered stock market prediction and trading analytics platform using Python, LSTM, Streamlit, Plotly, and Yahoo Finance API.

## Features
- LSTM Stock Prediction
- Technical Indicators
- Candlestick Charts
- Sentiment Analysis
- Multi-Stock Comparison
- Interactive Dashboard

## Technologies
- Python
- Streamlit
- Plotly
- Scikit-learn
- Yahoo Finance API

The LSTM was trained with Keras and its weights are evaluated with NumPy at
runtime, so the app does not need TensorFlow installed.

## Run Project

```bash
streamlit run app.py
